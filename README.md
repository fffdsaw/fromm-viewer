# Fromm Viewer

Fromm 대화와 사진·영상·음성을 브라우저에서 확인하고 저장하는 뷰어입니다.

## 시작하기

Chrome에서 아래 확장 프로그램을 먼저 설치해 주세요.

**[확장 프로그램 다운로드](https://raw.githubusercontent.com/fffdsaw/fromm-viewer/main/chrome_extension.zip)**

1. 위 링크에서 ZIP 파일을 내려받아 압축을 풉니다.
2. `chrome://extensions`에 접속해 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누르고, `manifest.json`이 들어 있는 `chrome_extension` 폴더를 선택합니다.
4. https://fffdsaw.github.io/fromm-viewer/?v=95 링크로 접속합니다
5. Fromm Viewer 페이지를 새로고침하고 이메일 확인 후 로그인합니다.

## 사용 방법

- **아티스트 선택:** 왼쪽 위 ☰ 버튼으로 메뉴를 열고 아티스트를 선택합니다. 같은 버튼이 X로 바뀌며, 다시 누르면 메뉴가 닫힙니다.
- **기록 보기:** 전체 대화·미디어·사진·영상·음성 탭에서 원하는 항목을 확인합니다. 스크롤하면 다음 기록을 불러옵니다.
- **대화 찾기:** 전체 대화 탭의 돋보기 버튼으로 내용을 검색하거나 날짜를 선택해 이동합니다.
- **사진 확대:** 사진을 더블클릭하면 원본을 크게 볼 수 있습니다.
- **파일 저장:** 개별 다운로드 버튼을 누르거나, 여러 항목을 선택한 뒤 **저장**을 누르면 폴더를 한 번만 선택합니다. 이후 선택한 파일은 자동으로 저장되며, 이전 버전에서 받은 백업 파일도 확인해 이미 있는 항목은 건너뜁니다. 실패한 항목만 다시 시도할 수 있습니다.
- **라이브:** 상단의 **라이브** 버튼에서 현재 방송 상태를 확인합니다.

## 로그인 정보

로그인 유지에 필요한 정보는 현재 브라우저에 저장되며, 비밀번호는 저장하지 않습니다. 사용을 마치고 로그인 정보를 지우려면 상단의 로그아웃 버튼을 눌러 주세요.
