# Fromm Viewer

Fromm 계정으로 대화·사진·영상·음성을 확인하고 저장하는 웹 뷰어입니다. 투표 결과 조회와 LIVE·Replay·Channel 영상 보기도 제공합니다. 조회·시청에는 해당 계정의 구독·이용 권한이 필요합니다.

**[Viewer 열기](https://fffdsaw.github.io/fromm-viewer/)**

## 설치

### 1. 사용할 기능에 맞게 다운로드

배포 버전 확인: 2026-10-29. Windows LIVE 패키지에도 같은 확장프로그램이 들어 있으므로 둘 다 받을 필요는 없습니다.

| 사용할 기능 | 다운로드 | 사용 환경 |
| --- | --- | --- |
| 대화·미디어·투표·Replay·Channel | [Chrome 확장프로그램 1.0.9](https://raw.githubusercontent.com/fffdsaw/fromm-viewer/main/chrome_extension.zip) | PC Chrome·Edge |
| 위 기능 + Windows Native LIVE | [확장프로그램 1.0.9 + LIVE 도구 0.5.0](https://github.com/fffdsaw/fromm-viewer/releases/download/native-live-0.5.0/fromm-native-live-windows-x64.zip) | Windows 64비트 Chrome·Edge |

macOS·Linux에서는 PC Chrome·Edge에 확장프로그램을 설치해 일반 기능을 이용할 수 있습니다. **Native 도구가 필요한 LIVE는 Windows PC 전용**입니다. 모바일·Safari에는 이 확장프로그램 설치 절차를 적용할 수 없으며, 별도 설치 방법이나 전체 기능 호환성을 보장하지 않습니다.

Windows LIVE에는 위 배포 ZIP을 사용하세요. GitHub의 **Code → Download ZIP**으로 받는 소스에는 LIVE 실행에 필요한 런타임이 포함되어 있지 않습니다.

### 2. 처음 설치하는 경우

1. 받은 ZIP을 계속 사용할 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. 브라우저 주소창에 Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장프로그램을 로드**를 눌러 `chrome_extension` 폴더를 선택합니다. ZIP 전체 폴더가 아닌 `manifest.json`이 들어 있는 폴더입니다.
4. 확장 목록에서 **Fromm Stream Nexus Proxy**가 켜져 있고 버전이 **1.0.9**인지 확인합니다. 이전 Fromm 확장프로그램이 있다면 꺼서 **하나만 활성화**합니다. Chrome과 Edge를 모두 사용한다면 각 브라우저에 설치합니다.
5. **Windows Native LIVE를 사용할 때만** 같은 패키지의 `native-live/Install-Web-LIVE.cmd`를 실행합니다. 현재 Windows 사용자에게 Chrome·Edge 연결을 등록하며, 관리자 권한이나 별도 Node.js 설치는 필요하지 않습니다.
6. [Viewer](https://fffdsaw.github.io/fromm-viewer/)를 열고 다음 로그인 절차를 진행합니다. 설치 전에 열어 둔 Viewer 탭은 새로고침합니다.

설치한 확장 폴더와 LIVE 도구 폴더는 이동하거나 삭제하지 마세요. 폴더를 옮겼다면 확장을 새 경로에서 다시 로드하고, Windows LIVE 도구도 새 경로의 `Install-Web-LIVE.cmd`로 다시 등록해야 합니다. 새 경로의 확장을 켜기 전 이전 확장은 끕니다.

### 3. 기존 설치를 교체하는 경우

1. 재생 중인 LIVE를 종료하고 Viewer 탭을 모두 닫습니다.
2. 위 표에서 필요한 최신 ZIP을 받습니다. 기존 **같은 경로**를 유지한다면 새 파일로 교체합니다. 새 폴더를 쓴다면 앞으로도 유지할 경로에 압축 해제합니다.
3. 확장 관리 화면에서 기존 폴더를 갱신했다면 해당 확장 카드의 **새로고침**을 누릅니다. 새 경로라면 이전 확장을 끈 뒤 새 `chrome_extension` 폴더를 로드합니다. 버전 **1.0.9**와 중복 활성화 여부를 확인합니다.
4. **Windows LIVE 도구를 교체했거나 폴더를 옮겼다면** 새 파일의 `native-live/Install-Web-LIVE.cmd`를 다시 실행합니다. 확장만 교체한 경우에는 필요하지 않습니다.
5. Viewer를 다시 열어 강력 새로고침합니다. Windows·Linux는 **Ctrl+F5**, macOS는 **⌘+Shift+R**을 사용합니다. 로그인 화면이 나타나면 아래 절차로 로그인합니다.

확장프로그램과 PC LIVE 도구는 자동으로 업데이트되지 않습니다. **Viewer 새로고침만으로 설치 파일이 교체되지는 않습니다.** 웹 화면만 바뀐 경우에는 매번 재설치할 필요가 없습니다.

### 4. 로그인

1. **Fromm 가입 이메일**을 입력하고 **이메일 확인**을 누릅니다.
2. 확인이 완료되면 **비밀번호**를 입력하고 **로그인**을 누릅니다. **고급 옵션**은 일반 설치에서 변경할 필요가 없습니다.
3. 왼쪽 메뉴 **☰**에서 아티스트를 선택합니다.

이메일 확인에 실패하면 확장프로그램이 해당 브라우저에서 켜져 있는지 확인하고 Viewer를 새로고침합니다. 로그인 유지를 위해 이메일·Access Token(접근 토큰)·Device ID(기기 식별자)를 브라우저에 저장하며, 비밀번호는 저장하지 않습니다.

## 사용

### 대화·검색·날짜 이동

- **☰ → 아티스트 → 전체 대화**에서 대화를 읽습니다. **미디어·사진·영상·음성** 탭으로 종류별로 모아 볼 수 있습니다.
- **전체 대화 → 돋보기 → 채팅 검색**에 검색어를 입력합니다. **전체 대화 함께 보기**로 주변 대화를 함께 읽고, 상단 **↑·↓**로 일치 항목 사이를 이동할 수 있습니다.
- 같은 창의 **날짜 선택 → 이동**으로 해당 날짜를 찾습니다. 달력의 파란 점은 불러온 대화가 있는 날짜를 나타냅니다.

### 내 글에 온 답장

**전체 대화 → 돋보기 → 내 글에 온 답장**을 켜면 전체 대화 속에서 본인에게 온 답장을 찾습니다. 상단 **↑·↓**로 이동하고, **전체 대화 함께 보기**를 끄면 답장만 모아 봅니다. 인용 카드를 누르면 검색·답장 필터를 해제하고 원문으로 이동합니다.

작성자 정보가 없는 과거 기록 등은 본인 답장으로 확인되지 않을 수 있습니다. [답장 판정 기준과 한계](MY-REPLIES.md)를 참고하세요.

### 사진·영상·음성 및 일괄 저장

- 사진·영상은 **한 번 클릭해 선택**, **두 번 클릭해 확대·재생**합니다. 음성은 항목의 재생 컨트롤을 사용합니다.
- 여러 항목을 선택한 뒤 상단 **저장**을 누릅니다. **전체선택**도 사용할 수 있으며, PC에서는 **Shift+클릭**으로 범위를 선택하거나 마우스로 영역을 드래그할 수 있습니다.
- 폴더 저장을 지원하는 브라우저에서는 저장 폴더를 선택하고 기존 파일을 건너뜁니다. 그 외에는 파일별 다운로드를 사용하며, 이 방식은 기존 폴더의 중복 파일 검사를 보장하지 않습니다.
- Replay·Channel 목록에서도 여러 영상을 선택해 저장할 수 있습니다. 이때 **전체선택**은 현재 채널·필터에서 **이미 불러온 영상**을 대상으로 합니다.

남은 대화·미디어 정보는 백그라운드에서 준비하며, 원본 파일을 미리 전부 내려받지는 않습니다. [선택 조작](DIRECT-SELECTION.md), [폴더 저장·재시도](MEDIA-BULK-SAVE.md), [로딩·백업 호환성](MEDIA-PERFORMANCE.md)에 자세한 내용을 정리했습니다.

### 투표

전체 대화의 투표 카드 또는 상단 **투표** 탭에서 질문·선택지·공개된 득표율과 아티스트 선택을 확인합니다. 공개 조건에 따라 일부 결과는 표시되지 않을 수 있습니다. 선택지 사진은 **사진 저장**으로 내려받고, 결과 창은 바깥 클릭이나 **Esc**로 닫습니다.

**투표 참여·작성·수정은 제공하지 않습니다.** [투표 조회 안내](VOTES.md)를 참고하세요.

### LIVE·Replay·Channel

상단 **라이브** 버튼을 누르면 **LIVE → Replay → Channel** 탭이 나타납니다.

| 탭 | 내용과 조작 |
| --- | --- |
| **LIVE** | 진행 중인 방송을 선택해 시청합니다. Native 도구가 필요한 방송은 Windows 설치를 먼저 완료해야 합니다. |
| **Replay** | 다시보기 영상을 선택하고 재생 버튼으로 엽니다. |
| **Channel** | 구독 채널을 선택해 업로드 영상을 봅니다. 대화의 **영상** 탭과는 별도 목록입니다. |

Replay·Channel은 목록 아래쪽으로 스크롤하면 다음 영상을 자동으로 추가합니다. 오류가 나거나 자동 로딩이 지원되지 않으면 표시되는 추가 로딩·재시도 버튼을 사용합니다. 재생 화면에서는 **← Replay** 또는 **← Channel**로 목록에 돌아갑니다. 목록과 재생 화면의 **↓ 다운로드** 버튼으로 개별 영상을 저장할 수 있습니다.

### Replay·Channel 플레이어

- 영상 하단 재생바에서 **재생·일시정지, 재생 위치, 음량·음소거**를 조절합니다. 재생 중 숨겨진 재생바는 포인터를 움직이거나 화면을 터치하면 다시 나타납니다.
- **재생 설정(톱니바퀴) → 화질**에서 서버가 제공하는 실제 화질을 고릅니다. **새 영상을 열 때마다 제공되는 최고 화질로 시작**하며, 끊겨도 자동으로 낮아지지 않습니다. 끊김이 계속되면 직접 낮은 화질을 선택하세요. 단일 화질 영상은 다른 화질을 고를 수 없습니다.
- 같은 설정에서 **재생 속도**와 **좌우 90도 회전**을 조절합니다. 작은 화면에서는 음량도 설정 안에 있습니다.
- 재생바의 **PiP(화면 속 화면)**·**전체 화면** 아이콘은 브라우저가 지원하는 경우 사용할 수 있습니다. 웹 전체 화면에서도 재생바와 화질 설정을 사용합니다.
- 재생 화질을 낮춰도 **다운로드는 제공되는 최고 화질**을 사용합니다. 회전은 화면 표시에만 적용되며 저장 파일과 기본 PiP 영상 방향은 바뀌지 않습니다.

브라우저·운영체제에 따라 PiP·시스템 전체 화면의 동작과 회전 적용이 다를 수 있습니다. [플레이어·화질 안내](VIDEO-QUALITY.md), [Channel 안내](CHANNEL-VIDEOS.md)를 참고하세요.

### LIVE 플레이어·댓글

- Windows Native 방송을 선택하면 도구가 **별도 창 없이 백그라운드에서 실행**됩니다. 영상은 Viewer에 표시되고 소리는 PC 도구에서 나옵니다. LIVE를 떠나거나 Viewer 탭을 닫으면 연결이 종료됩니다.
- 하단의 **PiP(화면 속 화면)**·**전체 화면**과 **LIVE 재생 설정 → 좌우 90도 회전**을 사용합니다. PiP에는 영상만 표시되고 댓글·조작 버튼은 포함되지 않습니다. 회전은 웹 표시용이며 PiP는 원본 방향을 사용합니다.
- **음량:** 웹에서 직접 재생하는 방송은 웹 음량·음소거를 사용합니다. **Native 방송은 웹 음량 버튼을 제공하지 않으므로 Windows 시스템 음량이나 볼륨 믹서에서 조절**합니다.
- **댓글 보기**를 누르면 댓글과 입력창이 나타납니다. 내용을 입력한 뒤 **전송**을 누릅니다. 계정·방송의 전송 권한에 따라 제한될 수 있으며, **댓글 숨기기**로 닫습니다. 이전 댓글을 읽는 동안에는 새 댓글을 따라 내려가지 않으며, 아래로 이동하는 버튼으로 최신 댓글을 다시 따라갈 수 있습니다.

실시간 LIVE에는 **재생 위치 탐색·배속·화질 선택이 없습니다.** 설치·연결 문제는 [웹 LIVE 안내](WEB-LIVE.md), 조작 방식은 [LIVE 플레이어 안내](LIVE-PLAYER-UI.md), 선택적 진단은 [LIVE 진단 안내](LIVE-DIAGNOSTICS.md)를 참고하세요.
