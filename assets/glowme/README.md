# Glow ME 참고 자산

사용자가 제공한 `Fromm_Viewer_GlowME_Codex_Package.zip`의 가로형 로고를 바탕으로 합니다. 최신 사용자 요청에 따라 이미지 편집 도구로 사각 카드 배경을 제거하고, 투명 PNG(478×263)로 정리했습니다. CSS의 둥근 프레임도 제거했습니다. 시험용 앱 아이콘은 변경하지 않았습니다. 생성 이미지의 인물·대화·URL·날짜는 포함하지 않습니다.

`icon-192.png`, `icon-512.png`, `favicon-32.png`, `reference-windows.ico`는 제공된 프로토타입입니다. 크기만으로 원본 선명도가 향상된 것은 아닙니다. `maskable`로 잘못 선언하지 않았습니다. 정식 아이콘의 16px 선명도·마스커블 안전 영역·Windows 설치 아이콘은 추가 디자인 검수가 필요합니다. ICO는 참고 파일이며 Native 프로그램이나 설치 파일을 변경하지 않습니다.

PWA 자체 설치 동작과 아이콘 디자인 완성도는 별도로 보고합니다. 이 브랜치는 Draft이며 사용자 승인 전 배포하지 않습니다.

## 독창적인 Liquid Glass 재료

`liquid-header.webp`: AI 이미지 도구로 새로 제작한 추상 물/유리 소재입니다. 공식 앨범아트·로고를 입력하거나 복제하지 않았으며, 글자/인물/인터페이스가 없습니다. 원본 생성 이미지를 웹 전송용 WebP 1600×600, quality 82로 인코딩했습니다(61,810 bytes). 헤더의 장식 배경으로만 사용하며 대화/영상 위에 입히지 않습니다. 추가 JS, 캔버스, WebGL, 움직이는 왜곡 필터가 없습니다. PWA 아이콘은 그대로입니다.

CSS는 실제 광선을 추적하지 않습니다. 이 정적 재료의 광학 반사·굴절과 CSS의 안팎 경계 반사/곡면 하이라이트를 합성해 유리처럼 보이도록 합니다. 텍스트는 왜곡하지 않습니다. 서비스워커의 캐시 허용 목록은 변경하지 않았으며, 재료 파일은 일반 정적 자산 요청 1개로 로드됩니다.

로고 교체에 맞춰 공개 아트워크 캐시 버전을 v2로 올렸습니다. 기존의 정적 이미지 4개 허용 목록/민감정보 캐시 금지/강제 업데이트하지 않는 동작은 유지합니다.
