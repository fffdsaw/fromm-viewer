# Glow ME 참고 자산

사용자가 제공한 `Fromm_Viewer_GlowME_Codex_Package.zip`의 가로형 로고와 시험용 아이콘을 그대로 사용합니다. 생성 이미지의 인물·대화·URL·날짜는 포함하지 않습니다. 로고 배경을 제거하거나 확대 재생성하지 않았습니다.

`icon-192.png`, `icon-512.png`, `favicon-32.png`, `reference-windows.ico`는 제공된 프로토타입입니다. 크기만으로 원본 선명도가 향상된 것은 아닙니다. `maskable`로 잘못 선언하지 않았습니다. 정식 아이콘의 16px 선명도·마스커블 안전 영역·Windows 설치 아이콘은 추가 디자인 검수가 필요합니다. ICO는 참고 파일이며 Native 프로그램이나 설치 파일을 변경하지 않습니다.

PWA 자체 설치 동작과 아이콘 디자인 완성도는 별도로 보고합니다. 이 브랜치는 Draft이며 사용자 승인 전 배포하지 않습니다.
