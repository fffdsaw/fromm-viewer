## 설정창

PC 설정 → `고성능 제한 해제 (시험)` OFF(기존) / ON(실험). 기본 OFF이며 기존 굴절·두께·흐림·채도·밝기·광택 슬라이더가 그대로 엔진 설정값을 조정한다.

ON에서만 추가로 `색수차 (고성능)` 기본 0.18, `광학 맵 해상도 (고성능)` 기본 2× 를 직접 조절할 수 있다. 실제 Meapri 내부는 `quality:'high'`에서만 색수차를 활성화한다. 0.12 초과인 색수차 값에서 R/G/B 분리 SVG 필터 경로를 만든다. 엔진 구현 내부 한계는 따르며 수치가 클수록 더 예쁘거나 반드시 빠른 것은 아니다.

## ON 모드에서 제거한 주요 성능 제한

- 소형 컨트롤 엔진 최대 8개 제한 해제 → 화면에 보이는 적격 컨트롤 모두 대상
- 엔진 생성 프레임당 2개 제한 해제
- 영상 재생 시 소형 컨트롤 광학 렌즈를 해제하는 정책 우회
- RAM 2GB/CPU 2코어 감지 시 소형 렌즈 비활성화 정책 우회
- `quality:'balanced'`→`'high'`, `mapPixelRatio:1`→설정 값
- 메뉴/소형 컨트롤의 굴절 35%/기타 곱셈 제한과 두께 8 상한 해제; UI 굴절·두께·흐림·채도·밝기·광택 슬라이더를 직접 사용
- `edges:true`, 유저 설정 색수차. `chromatic` 변경 시 렌즈 재생성으로 기존 필터 경로 갱신
- 첫 선택 시 나타나는 저장 캡슐의 저사양 제한 우회, high 품질·색수차 적용, 안정화 직후 렌즈 자동 폐기 생략

## **의도적으로 유지하는 기술·안전 경계**

- 접근성 설정 (`prefers-reduced-motion`, `prefers-reduced-transparency`, 강제 색상), 로그인 상태, 지원하지 않는 브라우저의 기본 대체 효과
- 화면 밖·제거된 컨트롤 정리, 숨겨진 탭에서 정지, DOM/이벤트 및 SVG 자원 폐기
- 실제 클릭 영역·포커스·글자 가독성, 기존 인증/채팅/영상/다운로드/LIVE 로직 보존
- 설정값 변경 알림 160ms 묶음(드래그 중 과도한 재생성 방지), 엔진 내부 계산 및 브라우저 자체 GPU·메모리 보호
- 모바일에는 PC 설정이 없으므로 기존 모바일 렌더링 경로 유지
- 기존 상단/사이드바 **대형 패널은 현재 PR #123 레이아웃에서 단색/그라데이션 스타일이며**, 이번 고성능 모드는 해당 패널을 새 광학 엔진으로 교체하지 않는다.
