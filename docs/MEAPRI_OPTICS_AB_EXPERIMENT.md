# Meapri 강화 광학 A/B 시험 (2026-11-15)

## 목적

ybouane으로 엔진을 바꾸기 전에 현재 Fromm Viewer의 Meapri에서 막아 둔 시각 효과를 켰을 때 얼마나 달라지는지 비교한다. 2026-11-15에 PR #123 HEAD `ad7c01c8`에서 독립된 `experiment/meapri-optics-ab-20261115` 브랜치를 생성했다. Draft PR #124의 **base는 PR #123 브랜치**이며 원본 작업을 변경하지 않는다.

## 사용자 전환 방법(이 브랜치가 실행되는 환경에서만)

PC `설정` → `유리 질감 강화 (시험)` 스위치 OFF(기존 기본) / ON(강화)를 전환한다. 기본값은 OFF. 로컬 설정 `fromm.pcGlass.v1`에 boolean `enhanced`만 추가되며 기존 저장값은 유지된다.

이 브랜치는 GitHub에만 있으며 **실제 사이트 `fffdsaw.github.io/fromm-viewer/`에는 배포하지 않았다.** 라이브 계정 로그인은 허용된 확장프로그램 사용 환경에서만 가능하다. 별도 앱·서버·브라우저 확장 기능 변경 없음.

## 변경 범위

- `web-glass-settings.js`: 기존 PC 설정창에 실험 모드 ON/OFF를 추가. 저장 및 초기화 처리.
- `web-glass-controls.js`: ON일 때 소형 컨트롤에만 색수차 `0.18`(엔진의 색수차 임계값 `>0.12`), `edges:true`, 메뉴 굴절 배율 `0.35→0.52`, 메뉴 두께 최대 `8→14`, 반사광 강도 상승. 색수차 렌더링 경로 재생성을 위해 ON/OFF 변경 시 소형 렌즈만 폐기·재생성.
- OFF는 기존 광학 값 유지. `web-glass.js`, `web-capsule-materialize.js`, 엔진 원본 벤더 코드, 인증·LIVE·영상·다운로드 경로는 변경하지 않는다.

## 보호 기능 유지

동시에 실행하는 광학 렌즈 **최대 8개**, 화면 밖 해제, 동영상 재생 중 광학 효과 제거, 저사양 장치·접근성·비활성 탭 대체, 프레임당 최대 2개 생성 등 기존 보호 기능은 그대로 둔다. `mapPixelRatio:1` 및 `quality:'balanced'`는 유지해 성능 비용을 통제한다.

## 검증 계획과 현재 범위

- GitHub API로 두 설정파일의 변경과 기반 SHA를 확인했고 수정 범위가 두 소스 파일뿐임을 확인했다.
- 동작 검증 필요: OFF 모드의 시각 회귀 없음, ON 모드의 실제 색수차/굴절/반사광 표시, ON↔OFF 시 색수차 렌즈 재생성 및 누수 없음, 브라우저 새로고침/설정 초기화, 실시간 채팅, 미디어 재생, 메뉴 이동, 클릭 영역·키보드 포커스.
- 합성 계정/데이터를 사용하는 브라우저 CI, Windows Chrome/Edge, 실제 사용자 GPU 및 Safari/Firefox 테스트는 완료되기 전까지 '통과'라고 말하지 않는다.
- 실험 수치 `0.18`, `0.52`, `14`는 시작값일 뿐 애플과 동일하다고 주장하지 않는다.

## 운영 방침

독립 비교 후 Meapri 기본/강화/ybouane 중 최종 선택할 때까지 기존 Meapri를 제거하지 않는다. 사용자 승인 없이 `main`·PR #123에 병합하거나 공개 배포하지 않는다.
