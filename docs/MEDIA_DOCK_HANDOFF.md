## 구현 체크포인트

- `web-glowme.js`/`glowme.css`: 메뉴 행 사이의 틈을 지나도 동일 캡슐을 유지. 개별 행의 hover 배경/그림자 및 변환/불투명도 전환을 제거하고 rAF에서 하나의 배경만 즉시 이동시켜 잔상을 없앰. 현재 선택은 기존 ARIA/글자 강조로 유지.
- PC 미디어/사진/영상/음성에서 정렬 버튼을 `mediaActionDock`으로 이동. 헤더와 목록 사이에 실제 도크 높이에 맞는 공간을 예약해 가운데 정렬하고 스크롤 후에도 상단 12px에 고정. 기존 버튼/ID/정렬 호출은 재사용.
- 선택 시 같은 도크에 선택 수·전체 선택·저장·선택 해제 표시. 원형 선택 아이콘으로 도구를 접거나 펼침. 접어도 선택 유지, 0개면 자동 숨김. 정상 PC에서 도구 열림으로 목록 위치가 바뀌지 않음. 모바일은 기존 정렬/하단 도구 배치 유지.
- `index.html`: `clearDownloadSelection()`은 지연 클릭 타이머도 취소하며 UI 선택/범위 앵커만 해제. 진행 중 저장을 중단하거나 다른 채널 선택을 삭제하지 않음. PC 미디어에서는 어디서나 Esc로 해제하되 입력칸/미리보기/모달/전체 화면/드래그 취소가 우선.
- `web-view-state.js`: PC 포함 미디어 맨 위 이동에 260~650ms ease-out 스크롤/동기화된 작은 버튼 애니메이션. 휠·터치·포인터·탭 변경 시 취소. 동작 감소 설정은 즉시 이동. 이동 중 배경 render가 이전 위치 복원을 예약해 중간에 멈추지 않도록 보호. 전체 대화의 가상 창 초기화는 기존 즉시 이동 유지.
- CSS/UI/View 스크립트의 동일 공개 버전 query를 `media-dock-20261106`으로 갱신. 인증/서명 URL 정책과 무관한 정적 UI 자산 캐시 키만 변경.

- 신규 `media-action-dock.browser.cjs`: PC1440 간격 중앙·상단 고정·선택/접기/해제·목록 위치 유지·미리보기 Escape 우선·중간 렌더 중 위로 이동·사용자 휠 중단·동작 감소·캡슐 잔상 방지 통과. 모바일390은 기존 정렬 위치/넘침 최소 확인.
