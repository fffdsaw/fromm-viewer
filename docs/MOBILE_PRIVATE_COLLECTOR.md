# 모바일 전용 개인 대화 JSON 수집기 (검토용 브랜치)

> 구현 상태: 코드와 합성 테스트 대상. 실제 프롬 계정/휴대폰에서 메시지 수집·파일 저장은 **미검증**입니다.
> 이 브랜치는 main/공개 GitHub Pages에 병합하거나 배포하지 않았습니다.

## 목적

기존 Work 산출물 `Fromm_Private_Analysis_Kit_v1.zip`의 `collector.js`를 모바일 프롬웹용 버튼으로 이식합니다.
사용자가 직접 선택한 본인 채팅방만 읽고, 결과를 휴대폰 안에 JSON으로 내려받습니다. PC에서는 수집기 스크립트를 다운로드하거나 실행하지 않습니다.

## 휴대폰 사용 순서 (기능 배포·사용자 승인 이후)

1. Firefox Android 등 **기존 Fromm Viewer에 정상 로그인하고 실제 대화 목록을 조회할 수 있는 모바일 브라우저**로 프롬웹을 엽니다. 로그인/API 연결 자체가 되지 않으면 수집기도 작동하지 않습니다. 데스크톱 사이트 모드는 끕니다.
2. 화면 오른쪽 아래 **내 대화 수집** 버튼을 누릅니다.
3. 5명 중 한 명을 고른 뒤 **실제 채팅방**을 확인합니다. 이름이 정확히 일치할 때만 자동 선택하므로 `헌이` 같은 별명은 직접 선택해야 합니다.
4. 기본 최대 20페이지(서버가 500건 제한을 허용하면 약 1만 건) 또는 확장 최대 60페이지(약 3만 건)를 선택합니다. 1페이지가 실제 몇 건인지는 서버 응답에 따라 다릅니다.
5. **선택 멤버 수집 시작**을 누릅니다. 최소 1초 간격으로 페이지를 순차 조회합니다. 진행 중에는 브라우저를 계속 화면에 띄우고, 새로고침·로그아웃·앱 전환을 하지 않습니다.
6. 끝나면 `star` 이외의 사용자 유형 예시를 확인해 **내가 직접 보낸 메시지임이 확실한 유형만** 체크하고, 직접 확인란도 체크합니다. 확인하지 않으면 `unknown`으로 남습니다.
7. **JSON 파일 휴대폰에 저장**을 누르고 **내 파일 → 다운로드**에서 저장 여부를 확인한 뒤 다음 멤버를 진행합니다.
8. 5명 파일을 확인한 후, **토큰이나 비밀번호 없이** 비공개 대화 내용 중 가릴 항목을 추가로 확인하고 분석용으로 전달합니다.

## 보안·개인정보

- 조회는 이미 로그인한 프롬웹의 `frommApiJson`과 `extractMessages`만 사용합니다. **다른 서버·외부 AI·GitHub로 자동 업로드하지 않습니다.**
- 파일은 Work 분석 키트의 `conversation.schema.json`과 호환되는 스키마 v1.0.0으로 작성합니다.
- 내보내기 대상은 작성 시각, 아티스트, 메시지 종류, 텍스트, 가명 참조, 답장 대상이 확인된 경우의 참조 등 제한된 필드입니다. 인증값, 사용자·채팅방·원본 메시지 ID, 미디어 URL, 원본 API 응답 전체는 저장하지 않습니다.
- 이메일·전화번호·웹 URL·일부 인증 문자열은 자동 가리지만 모든 개인정보를 탐지하지는 못합니다. **대화 텍스트 자체는 비공개 데이터**이므로 수동 검토가 필요합니다.
- 401/403, 429 오류에서는 자동 재시도하지 않고 멈춥니다. 중단/페이지 제한/타임스탬프 경계의 결과는 `partial` 파일로 구분합니다.
- 메모리 보존을 위해 페이지 상한을 두며, 결과는 다운로드 전에 브라우저 메모리에만 머뭅니다. 페이지를 닫으면 미저장 결과가 사라집니다.
- `api-range` 표시는 API 범위에서 더 이상 이전 메시지가 나오지 않았다는 의미이지, 계정의 모든 기록 보유·삭제된 메시지까지 증명하지 않습니다.

## PC 기존 기능 보존

`index.html`의 기존 모바일 전용 분기 안에서만 `mobile-private-collector.js`를 동적 로드합니다. PC는 자바스크립트 파일을 요청하지 않고 추가 버튼도 나타나지 않습니다. 메인 화면·브리지·LIVE·미디어 기능은 수정하지 않습니다.

## 검증 및 후속 작업

- 합성 메시지에 대해 중복·경계 처리·권한 오류·페이지 상한·가명 참조·개인정보 필드 제외·사용자 유형 확인 등을 Node 테스트로 검사합니다.
- Android Firefox에서 실제 로그인/대화방 목록/API 호출/블롭(JSON) 다운로드를 실사용 검증해야 합니다.
- 사용자 승인 없이 main에 병합하거나 공개 배포하지 않습니다.
