로딩 안내의 y0는 유효한 읽기 위치가 아니므로 저장하지 않습니다. 새 진입은 최신 메시지를 보이는 위치에서 시작하고, 이미 유효한 읽기 anchor가 있다면 기존 복원을 보존합니다. 대화의 시간순 정렬과 전체 기록 데이터 준비 방식은 그대로입니다. 최초 로딩 중 실제 탐색 버튼을 통한 사진/대화·미디어/대화 복귀, 준비 완료 직후의 최신행 가시성·가상 창·스크롤 최하단, 로딩 전 저장된 읽기 anchor의 유지를 검증했습니다. 기존 검색·날짜·답장 및 지연 미디어 anchor 회귀도 통과했습니다.

실제 OS 설치형 PWA/Windows·Safari/실계정 대화는 미검증입니다. 필수 CI/병합·배포와 공개 origin 검증 결과는 후속 PR의 완료 기록을 확인하세요.
