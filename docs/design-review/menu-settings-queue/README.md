# 메뉴 알약·설정·영상 다운로드 대기열

기준 main `f20ede6`. 아티스트 목록의 스타일/선택 표시는 유지한다.

- 위쪽 메뉴/포인터 알약만 흰 중성 tint, blur0, saturation100으로 조절한다.
  설정의 굴절/두께/광택과 기존 SDK를 유지하며 강한 초록 덧칠을 걷어낸다.
- 첫 hover는 즉시 배치하고 이후 행 간 이동은240ms로 이어진다. 스크롤/떠남은
  즉시 정리한다. 동작 감소 설정에서는 이동하지 않는다.
- 메뉴의 이중 선택 테두리/그림자와 마우스 선택 후 강제 포커스를 제거한다.
  실제 키보드 탐색의 focus-visible 표시는 유지한다. 모바일 탐색은 기존 동작.
- ‘설정’으로 이름을 바꾸고 기존 앱 설치 버튼/이벤트를 PC 설정 안으로 이동한다.
  기존 설치 가능 여부를 따르며 PC→모바일 전환 시 원래 설치 위치로 돌려놓는다.
- Replay·Channel 개별 다운로드는 공유 FIFO 대기열로 접수한다. 기존 전송/복호화/
  파일 쓰기는 한 번에 하나씩 실행해 메모리와 세그먼트 순서를 유지한다.
  각 클릭의 원래 사용자 동작 안에서 저장 위치를 먼저 예약한다. 두 번째 영상은
  ‘대기’로 보이며 첫 전송 후 자동 시작한다. 같은 영상 중복은 합친다.
  취소한 대기 항목은 즉시 풀고, 로그인 변경은 예약 파일을 abort한다.
  선택 저장의 기존 잠금은 유지하며 종료 후 대기 요청을 이어받는다.
  대기 후 시작하는 Replay는 기존 강제 갱신 API로 새 다운로드 주소를 확인한다.
- 미디어/사진 개별 다운로드는 기존 동작을 유지한다. 브라우저에 넘긴 파일은
  기존처럼 ‘요청됨’으로 구분하며 저장 완료라고 표시하지 않는다.

검증: Node289PASS/기존 Agora 타입 SKIP1; 큐 순서/중복/취소/오류 후 진행/로그인
변경 파일 정리; 실제 두 탭의 다운로드 버튼 접수/대기/이어서 실행; 메뉴 중간 이동
좌표와 최종 정렬; 아티스트 표시 유지; 마우스/키보드 포커스; 설정 설치 이벤트와
모바일 위치 복원; 기존 설정/컨트롤/Channel 및 모바일 대표 화면 검사 PASS.
실제 OS 설치와 실계정 대용량 미디어는 미확인. 설치 유도 UI는 기존 브라우저 정책을 따른다.
