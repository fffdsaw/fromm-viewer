# 커서 렌즈와 다운로드 대기 회전 표시

이전 main `79ea5fd`의 커서 알약은 SDK에 연결돼 있었지만, 단색 민트 배경의
굴절은 실제 화면에 거의 차이를 만들지 않았다. 커서의 이동 carrier와 광학 face를
분리하고, 작은 중성 반사광 면을 face 뒤에 배치했다. 이 면을 기존 Meapri
`LiquidGlass`의 displacement/specular map으로 굴절한다. 대화·사진 복제,
WebGL 캡처, vendor 변경이나 새 의존성은 없다. 텍스트/아이콘은 렌즈 앞에 유지한다.

커서 렌즈만 tint 상한6%와 specular 기준32%를 사용한다. 기존 광택 설정은 이
기준에 더해지며, 굴절·두께는 기존 설정을 따른다. 이동은 같은 인스턴스와 맵을
재사용한다. 큰 민트 패널·선택 메뉴·아티스트 목록·240ms 이동은 유지한다.
지원되지 않는 환경과 영상 재생·저전력·접근성 설정의 기존 대체 경로도 유지한다.

다운로드 `queued` 상태는 기존 SVG의 무한 회전 링을 재사용한다. ‘대기’ 글자를
그리지 않으며, 접근 가능한 이름에는 ‘다운로드 대기 중’을 유지한다. FIFO,
중복 방지와 전송 순서에는 변경이 없다. 동작 감소에서는 고정된 링으로 표시한다.
진행률이 있는 실제 전송은 기존 진행 링, 완료·실패는 기존 상태를 사용한다.
