## 변경

- 답장/검색 이동의 한 번뿐인 스크롤 보정 뒤, 가상 행·이미지·폰트의 지연된 높이 변화로 대상이 화면 위로 밀릴 수 있었음. 기존 날짜 이동의 앵커 보정을 재사용하고, 답장 이동은 최대 1.5초 동안 소수 컨테이너의 크기 및 이미지/폰트 완료 이벤트만 추가 관찰.
- 모바일에서 대상과 가로로 겹치는 검색/답장 도크 아래에 말풍선을 정렬. 다른 이동·계정/필터 변경·수동 휠/터치/포인터/키 입력·탭 숨김 시 보정 중단. 시간 종료 시 관찰자와 이벤트 해제.
- ‘전체 대화 함께 보기’를 답장/검색 활성화 전에 독립 선택 가능. 답장 필터를 켜고 꺼도 명시적인 선택 유지. 초기값은 해제이며, 답장/검색 조건이 없으면 체크만 변경하고 대화 DOM·스크롤·서버 조회를 건드리지 않음.
- LIVE·Replay·Channel·인증·다운로드·Native·확장 코드는 변경하지 않음. Meapri 엔진도 기존 제한적 시험 적용 상태 유지.
