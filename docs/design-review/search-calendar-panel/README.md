- 브랜치 `fix/search-calendar-panel`, 기준 main `6973458725f5f7cbf08b6d4f91970e71a58a1605`.
- 참고 이미지의 구조 적용: 분리된 제목/닫기 → 채팅 검색 → 실제 체크박스2개 → 구분선 → 바로 열린 달력 → 넓은 이동 버튼.
- 현재 민트·그린 색과 접근성을 유지. 참고 이미지의 물결 장식·가상 날짜/콘텐츠는 복제하지 않음.
- ‘날짜 선택’ 활성화 단계를 생략. 선택 날짜는 유지하고 명시적으로 ‘이동’을 눌러 기존 날짜 이동 함수를 호출. 연도·월 전환/오늘/답장 판별·검색·문맥·로그아웃 처리 유지.
- ‘전체 대화 함께 보기’는 답장/검색이 있을 때 사용 가능. 체크박스 기본 해제이며 기존 답장 선택 시 문맥 기본값은 기존 정책과 동기화.
- 작은 화면에서는 제목/이동 버튼을 유지하고 중간 내용만 독립 스크롤. Chrome fieldset의 overflow 특성으로 날짜가 하단 버튼 위에 그려지는 결함을 별도 스크롤 래퍼로 수정.
- 로그인·LIVE·Replay·Channel·HLS·화질·다운로드 함수는 수정하지 않음. 수정한 index 함수는 체크박스 상태 표시와 달력 열기/선택 UI 이벤트뿐.

## 추가 피드백 진행 기록

- ‘내 글에 온 답장’의 기본값을 본인 답장만 표시하도록 변경. 주변 전체 대화는 별도 체크한 경우에만 표시. 실제 신고된 원문/API payload는 제공되지 않아 개별 오분류를 재현했다고 주장하지 않음.
- 인용 alias의 작성자/원문 ID 충돌 시 확인된 본인 답장으로 분류하지 않음. 렌더 때 작성자 변경 캐시를 갱신. 재선택 시 검색어/이전 위치를 초기화하고 가장 오래된 본인 답장1번으로 이동, 이전 비동기 선택 작업 취소.
- 맨 위로 버튼은 가상 대화 창을 실제 첫 범위로 재구성하고 이전 위치 복원/앵커 보정을 취소. 전체 대화에서 smooth-scroll과 prepend 보정이 충돌하는 경로 제거. 사용자 휠/터치가 있으면 보정 중단. 서버 요청을 새로 늘리지 않음.
- 달력 펼침220ms 애니메이션, 감소 모션 설정에서는 제거.
- 유리 엔진은 기존 최대5개 소형 컨트롤 시험 적용 그대로이며 본격 적용 아님. 로그인 전 모듈 로딩/초기화 지연, 유휴 시간에 한 컨트롤씩 준비, 사이드바 확장 중 렌즈 생성 연기 작업 진행 중.
