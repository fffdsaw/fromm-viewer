작업 브랜치: `codex/glowme-ui-integration-20261118`. 기준 main: `831ec88ff0e334818931782d26ef258a3f325215` (PR141 배포본). 사용자의 최신 지시에 따라 별도 브랜치를 만들고 이전 사진 개선 checkpoint를 보존해 가져왔다. **이번 변경은 PR 검토 대상이며 병합·공개 배포하지 않는다.**

## 구현

- Replay·Channel·미디어·음성·영상·사진 목록은 기존 실제 컨트롤을 공용 2줄 헤더로 이동한다. DOM/핸들러를 복제하지 않는다. 정렬은 오른쪽에 고정하며 모바일에서도 목록 위에 고정한다. 좁은 Channel/Replay 헤더는 제목/구독 필터를 위쪽 영역 안에서 두 줄로 배치한다.
- 일반 상단바, 선택 작업, 썸네일 다운로드/재생, 소형 플레이어 버튼은 `glowme-controls.css`의 즉시 적용되는 CSS 물방울이다. 얇은 림, 약한 반사광/음영, 테마 대비를 사용한다. 굴절·RGB 필터·SDK 인스턴스를 생성하지 않으며 설정 슬라이더와 분리했다. 포인터 반사광은 입력 시 좌표만 갱신하고 벗어나면 초기화한다.
- Channel은 실제 혼합 피드의 **전체 / 영상 / 사진**을 하나의 버튼으로 선택한다. 공개/구독/세션/실패/원본 응답 커서 처리는 기존 로더를 재사용한다. Artist 게시물 사진을 지원하는 것처럼 표시하지 않는다. 전체 피드에 Replay 항목을 섞거나 사진을 영상 자동 재생 큐에 넣지 않는다.
- `web-morph-menu.js`는 배포된 Meapri `LiquidMenu`의 위치·클립·머티리얼 애니메이션과 `LiquidGlass`를 재사용한다. 실제 유리 표면만 움직이고 메뉴 글자/클릭 영역은 고정한다. 최초 사용 때 SDK를 가져오므로 로그인 화면에 불필요한 엔진 요청을 추가하지 않는다.
- 펼친 메뉴는 기존 설정 singleton의 굴절·두께·흐림·채도·색수차·밝기/광택 및 ON/OFF를 사용한다. 공식 `scheme:'adaptive'`도 사용한다. SDK가 세 지점의 DOM 고체 배경색을 검사하는 방식이며 사진/영상 픽셀 판독·매 프레임 캡처·WebGL 복사는 아니다. 복잡한 이미지/그라데이션에는 SDK의 중립 대체와 테마 색상/명암을 사용한다. 메뉴가 닫히거나 내비게이션/resize/scroll/pagehide가 발생하면 애니메이션을 취소하고 SDK/필터/DOM을 해제한다. 앱 테마 변경에는 공식 `syncToBackdrop()`을 호출한다. 선택적 SDK 로드 실패/1.5초 지연 시에는 광학 효과 없는 네이티브 메뉴로 필터 기능을 유지하고, 지연 끝에 SDK 로드가 완료되면 다음 열기부터 실제 SDK를 사용한다. 로드 오류를 실제 광학 효과로 표시하지 않는다.
- 선택 0개에서는 작업 캡슐이 숨겨진다. 첫 선택 때 정렬 버튼 왼쪽으로 표면만 머티리얼라이즈되고 마지막 해제 때 오른쪽으로 수축한다. 기존 캡슐 모듈의 수평 CSS 경로를 사용하며 독립적으로 동작한다. 숫자 변경은 재시작하지 않고 빠른 반전은 같은 애니메이션을 되돌린다. 감소 모션은 즉시 표시한다. 일반 버튼을 광학 엔진에 묶지 않는다.
- 모바일 선택 캡슐도 헤더 내부 정렬 버튼 왼쪽에 들어간다. 선택 중에는 그 자리의 목록 정보/콘텐츠 필터가 잠시 가려지고 해제하면 돌아온다. 360px 이하에서 선택 수는 숫자로 압축하되 원래 DOM의 전체 한국어 문구와 툴팁은 유지한다. 목록 첫 카드/다운로드를 덮지 않는다.
- 기존 갤러리 정렬/전체 선택/저장을 재사용한다. Replay/Channel의 과거순은 기존 로더로 나머지 페이지를 확인한 뒤 **뷰 복사본**을 정렬한다. 원본 배열·커서 순서는 바꾸지 않는다. 전체 Channel에서 선택한 앨범 저장도 기존 사진 전송 함수를 재사용한다. 동영상 전송 엔진은 변경하지 않았다.
- 다운로드 SVG 회전 링의 키프레임·시계 방향·1초 주기·진행/완료/실패 상태를 유지한다. 색상만 `--theme-accent`로 연결하며 테마 변경 시 애니메이션 노드를 교체하지 않는다.
- 사진 카드의 좌측 검은 ‘사진’ 네임택을 제거했다. 우측 사진 열기/다운로드는 유지하고 사진 개수만 사진 아이콘 옆에 표시한다.
- 앞선 사진 요청도 포함했다. 원본 URL 확인을 기다리지 않고 현재/인접 제공 이미지를 디코딩해 재사용한다(최대 3장). 원본은 현재 사진만 병행 확인하며 늦은 응답은 현재 장을 덮지 않는다. 작은 카드 개수 메타데이터는 보이는 카드부터 최대 2개씩 확인하며 종료 시 취소한다. 서명 URL을 영구 저장하지 않는다.

## 기간 필터 및 보호 범위

최신 main의 6개 목록에는 독립적인 기간 범위 필터가 없다. 기존 달력은 **전체 대화 검색의 날짜 이동**이다. 없는 기간 기능을 추가한 것처럼 만들지 않았으며 기존 달력/설정/일반 팝업 구조도 변경하지 않았다. 따라서 목록 기간 메뉴 모핑은 적용 대상 없음이다. 추후 실제 기간 필터가 추가되면 공용 모핑 어댑터를 연결할 수 있다.

사이드바 설계/선택 렌즈, 기존 다른 영역의 정상 광학 효과, 인증/Fromm 프로토콜, 대화 캐시, 소형 플레이어 구조/재생/음량, Native LIVE/확장, 서비스 워커는 재설계하지 않았다. 기존 vendor JS/worker/LICENSE는 변경하지 않았다. 모핑에 새로 연결한 엔진은 펼친 Channel 콘텐츠 메뉴 하나뿐이다.
